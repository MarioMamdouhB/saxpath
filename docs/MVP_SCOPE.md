# MVP Scope

## In Scope for Phase 1

- Flutter mobile skeleton with a simple day-one learning flow
- FastAPI mock backend
- Docker Compose with PostgreSQL and API
- Arabic UI with simple navigation
- Mocked daily plan, lessons, and attempt evaluation

## Out of Scope

- Real audio playback
- Real recording
- Real AI or audio analysis
- Authentication
- Payments
- Social or community features
- Copyrighted songs

## First MVP Direction

Build a small, verifiable foundation that compiles, runs, and demonstrates the product structure without overengineering.
