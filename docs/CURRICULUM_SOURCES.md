# Curriculum Sources

This project does not copy protected university lesson packs, scores, or recordings.

Instead, the first-week saxophone curriculum is a normalized beginner sequence inspired by official public curriculum pages, degree bulletins, and studio handbooks from major music institutions.

External source links in this file were verified on 2026-05-09.

## How These Sources Are Used

- Beginner technique progression:
  posture, embouchure, breath, tonguing, notation, counting, and early scales
- Performance-core structure:
  private study, repeated practice, ensemble mindset, and checkpoint recordings
- Musicianship structure:
  ear training, harmony awareness, time/rhythm sequencing, and phrase repetition

## What Is Not Imported

- Full copyrighted sheet music
- Full protected lesson text
- Official institutional recordings
- Closed LMS/course portal materials

## Current Product Decision

The API currently serves an original first-week Arabic beginner sequence for alto saxophone.

That sequence is source-informed but still product-authored inside this repo so it can be expanded safely into:

- week 2 to week 12 lesson plans
- reusable exercise libraries
- public-domain repertoire packs
- original demo audio assets
