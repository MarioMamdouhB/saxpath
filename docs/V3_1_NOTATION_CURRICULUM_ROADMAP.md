# V3.1 Notation Curriculum Roadmap

Date: 2026-05-12

This document defines how `SaxPath V3.1` should turn notation learning into a complete in-app path with:

- `Beginner`
- `Intermediate`
- `Professional`

It also defines the `Tap / Clap / Count` system and the rule that every notation lesson must include practical drills inside the app.

## Main Goal

Notation in `V3.1` should stop feeling like small disconnected reading screens.

It should become a real path that teaches the learner:

1. how to see the symbol
2. how to count it
3. how to tap or clap it
4. how to hear it
5. how to play it on the horn
6. how to repeat it until it is stable

## Product Rule

Notation should not be taught as text.

Notation should be taught as:

`See -> Count -> Tap -> Hear -> Play -> Record -> Retry`

## V3.1 Notation Principles

- less explanation
- more doing
- one concept per lesson
- one clear practical target per screen
- tapping is not optional; it is a required bridge before playing
- no lesson should end at "I understood the symbol"
- every lesson must end at "I performed the symbol"

## Learner Outcome

By the end of the notation path, the learner should be able to:

- read from the staff with confidence
- understand note values and rests
- count pulse and subdivisions correctly
- tap rhythms before playing them
- connect notation to fingering and sax sound
- sight-read short phrases with stable timing
- handle articulation, phrasing, and reading pressure at higher levels

## Program Structure

The notation system should be divided into:

1. `Level`
2. `Module`
3. `Lesson`
4. `Drill`
5. `Record Check`
6. `Mastery Check`

## Levels

### Level 1: Beginner

Goal:

- make the learner comfortable with the staff, symbol reading, pulse, and first playable notation units

### Level 2: Intermediate

Goal:

- connect reading to flow, subdivisions, phrasing, note groups, and short sight-reading passages

### Level 3: Professional

Goal:

- make notation performance stable under musical pressure, including advanced rhythm, articulation, phrasing, and reading fluency

## Level 1: Beginner

### Beginner Outcome

The learner should leave this level able to:

- understand the five lines and four spaces
- recognize the treble clef
- locate notes on the staff
- understand beat and measure basics
- count simple note values and rests
- tap simple rhythms steadily
- read and play first-note combinations

## Tap / Clap / Count System

This must be a first-class part of V3.1, not a side note.

### Why It Matters

Many learners fail in notation not because they cannot see the note, but because they cannot internalize time before playing.

So V3.1 should require a rhythm bridge:

`Count -> Tap -> Clap -> Play`

### Tap Modes

The app should support these drill types:

1. `Finger Tap`
- light table or leg tapping
- useful before horn

2. `Clap`
- stronger body-based rhythm confirmation
- useful for note-value and rest training

3. `Count Out Loud`
- required for early rhythm lessons
- should appear visually in the UI

4. `Silent Internal Count`
- introduced later
- checked through timing-based drills

5. `One-Note Rhythm Play`
- same rhythm, one pitch only
- bridges rhythm into horn performance

### Tap Progression

Each new rhythm concept should follow this order:

1. see symbol
2. hear model
3. count aloud
4. tap or clap
5. repeat with metronome
6. play on one note
7. play on written notes
8. record attempt

## Lesson Template Inside The App

Every notation lesson in V3.1 should use one consistent structure.

### Lesson Screen

Contains:

- lesson title
- one-line objective
- visual notation card
- one short explanation only
- `Start Tap Drill` CTA
- `Start Play Drill` CTA

### Tap Drill Screen

Contains:

- visual beat guide
- count text
- metronome
- repeat target
- success state

### Play Drill Screen

Contains:

- same notation snippet
- playback demo
- optional fingering help
- count-in
- metronome or pulse support

### Record Check

Contains:

- one focused task
- one score or feedback direction
- one retry instruction

## Content Rules

### Rule 1

One concept per lesson.

### Rule 2

No notation lesson should open with a long paragraph.

### Rule 3

Every notation concept must include at least one tap/clap/count exercise.

### Rule 4

Every reading concept must end in horn performance.

### Rule 5

Intermediate and Professional levels must still stay drill-first, not explanation-first.

- define the 3-level notation curriculum
- turn the current notation area into `Beginner Level 1` instead of a small standalone lab
- add tap/clap/count as required lesson blocks
- make every beginner notation lesson end in a practical horn drill
- connect first-note reading to the existing foundation exercises

- add Intermediate modules for subdivisions, ties, articulation, and phrase reading
- add notation progress tracking
- add dedicated one-note rhythm drills and 2-bar reading drills

### Later

- add Professional modules for advanced rhythm, meter changes, expressive marks, and reading under pressure
- add original short studies and performance checks

## Final Direction

The notation topic in `V3.1` should not be:

`a few note-reading screens`

It should be:

`a full practical reading system from first symbol to confident musical execution, with tapping and horn drills inside the app at every level.`
