# Roadmap

## Phase 1: Foundation

Monorepo setup, mocked API, mobile skeleton, and local development environment.

## Phase 2: Core Learning Flow

Simple end-to-end learner flow from home to results.

## Phase 3: First 7 Days Curriculum

Expand mocked content into a structured first-week curriculum.

## Phase 4: Audio Playback + Metronome

Add controlled playback and metronome support.

## Phase 5: Recording

Add learner recording capture and upload flow.

## Phase 6: Pitch Detection POC

Prototype note accuracy detection.

## Phase 7: Rhythm Detection POC

Prototype timing and rhythm analysis.

## Phase 8: Private Beta

Validate usability and learning flow with early testers.
