# Product Brief

## Product Name

SaxPath

## Target User

Arabic-speaking beginner alto saxophone learners.

## Problem

Beginners need a simple, guided way to connect note reading, rhythm, and daily practice without being overwhelmed by advanced music tools.

## Solution

SaxPath provides a mobile-first, Arabic-first learning path with short lessons, practice guidance, and mocked feedback that can later expand into audio-assisted learning.

## Differentiation

- Arabic-first learner experience
- Focused specifically on beginner alto saxophone
- Short, structured learning flow instead of open-ended browsing

## First MVP Goal

Establish a clean technical foundation and a simple mocked learning flow that can grow into real lesson content, playback, recording, and feedback in later phases.
